# public/

Static assets served at the site root.

Place the ROQIT logo here as **`roqit-logo.png`** — it will appear in the
sidebar, the mobile top bar, and the login screen automatically. Until then the
app shows a plain "ROQIT" text wordmark.

(Optional: a square icon-only version at `src/app/icon.png` becomes the
browser-tab favicon.)
